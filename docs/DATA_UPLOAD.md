# 上传真实数据：最小列模板与常见坑

本项目的选址引擎接受两类入口：

- **终端**：`python run_agent.py "..."`（默认用内置样例）
- **网页**：`python app.py` 后打开 http://127.0.0.1:5001/agent（可上传文件）

上传是**可选**的；不传时使用 `sample_data/` 下的内置样例（深圳样例最完整）。

---

## 一、三个文件各是什么

| 文件 | 内容 | 是否必需 |
|---|---|---|
| stores（候选起降点） | 每个候选站点一行 | **必需** |
| rdcs（候选机坪） | 每个候选机坪一行 | 建议（缺省会回退到内置样例机坪） |
| distances（距离矩阵） | 机坪↔起降点距离 | 可选（缺省用球面距离兜底） |

支持 `.csv` / `.xlsx` / `.xls`。**列的顺序和数量不重要，多余的列会被忽略。**

---

## 二、最小列模板

### stores（候选起降点）

```csv
pad_id,lat,lon,rf_sales_10k
P1,22.6431,114.1579,500
P2,22.6531,114.1679,300
```

| 列 | 必需 | 缺省值 | 说明 |
|---|---|---|---|
| `pad_id`（或 `id`） | 是 | — | 唯一标识 |
| `lat` / `lon` | 是 | — | 经纬度 |
| `rf_sales_10k`（或 `annual_sales_10k`） | 是 | 0 | 需求单量，单位「万」；缺列则结果无意义 |
| `area_sqm` | 否 | 100 | 面积，㎡ |
| `city` | 否 | 见坑② | 所属城市 |
| `is_existing` | 否 | False | 是否存量 |
| `name` | 否 | 同 id | 名称 |

### rdcs（候选机坪）

```csv
vertiport_id,lat,lon,altitude_limit_m
V1,22.6431,114.1579,30
V2,22.6531,114.1679,25
```

| 列 | 必需 | 缺省值 | 说明 |
|---|---|---|---|
| `vertiport_id`（或 `id`） | 是 | — | 唯一标识 |
| `lat` / `lon` | 是 | — | 经纬度 |
| `altitude_limit_m`（或 `clear_height_m`） | 见坑③ | 0 | 净空高度（米） |
| `is_no_fly_zone` | 否 | False | 是否禁飞区（True 直接剔除） |
| `max_flight_radius_km` | 否 | 15 | 服务半径 |
| `area_sqm` | 否 | 10000 | 面积，㎡ |
| `city` | 否 | 见坑② | 所属城市 |

### distances（距离矩阵，可选）

```csv
vertiport_id,pad_id,distance_km
V1,P1,0.5
```

## 三、三个会导致「静默无结果」的坑

### ① 没有 `city` 列

引擎按 `city` 列过滤数据。缺列会让所有行被剔除，结果为空。

- 现状：上传时选择城市即可，程序会自动补 `city` 并给出提示。
- 若既没有 `city` 列、也没有指定城市，程序会直接报错提示，而不是返回空结果。

### ② `city` 列的值和所选城市不一致

同样会被过滤掉。请确认值属于 `beijing` / `hangzhou` / `shenzhen`（或 `北京` / `杭州` / `深圳`）。

### ③ 机坪表缺 `altitude_limit_m`

缺失值按 0 处理，会撞上 Stage3「净空 < 3 米直接剔除」硬约束，**所有机坪被过滤**，结果为空。
程序会给出明确警告，请补上该列（单位：米）。

---

## 四、还有一个几何约束（不是 bug）

**落在城市内环限制区内的点会被直接剔除**，对应三城空域限飞规则：

| 城市 | 内环限制区 | 近似半径 |
|---|---|---|
| 北京 | 五环内 | 15.5 km |
| 杭州 | 绕城内 | 12.0 km |
| 深圳 | 福田-罗湖中心区 | 6.0 km |

所以把测试点放在市中心时，会出现「合格机坪 = 0」；挪到环外即可正常出结果。

## 六、数据口径提醒

`rf_sales_10k` 是样例中的**合成需求权重**（单位：万），不是真实日单量。
接入真实业务时，请替换为真实订单去重单量；其余算法链路不变。
平均配送距离可能偏低，是因为样例中存在机坪与起降点同址的 0 距离边。
